## text/
Plain-text extracts of the searchable PDFs (pdftotext -layout), plus the OCR'd LOT FCOM (`lot_fcom.txt`). Inventory citations such as `stm.txt:2131` refer to line numbers in these files. Don't regenerate them, or the line numbers shift.

## ocr/
The three scanned PDFs (LOT FCOM, Honeywell FMS guide, CBT slides) OCR'd with Tesseract 5.4 at 300 dpi on 2026-11-19, with no failed pages. One `.txt` per PDF, with `=== page N ===` markers. To quote a figure, check it against the page image.

## Safety check (2026-11-19)
- **The differences notebook and its 10 attachments:** Defender found no threats. The attachments contain Flash (SWF) animations, which modern readers won't play, and 3D-viewer JavaScript. One script is heavily obfuscated (eval and unescape layers). It was decoded statically, without running it: it's the Right Hemisphere 3D-PDF view/part-info framework (rhInitVisibleObjects, views, cameras) and makes no network, file, launch or submit calls. The notebook's own JavaScript just initialises a form field. Avoid opening the attachments in old Acrobat versions with Flash enabled.
All 72 PDFs: Windows Defender found no threats. A static structure scan found no JavaScript, launch actions or disguised files. The only embedded file is an Acrobat accessibility report (HTML, no scripts) inside the MMEL Rev 18.
